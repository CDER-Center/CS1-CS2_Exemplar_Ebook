## Implementation Notes

This activity uses image processing as the context for introducing PDC concepts in CS2. The activity takes two 85-minute class meetings. The first class is used for lecture and sample-code demonstration. The second class is used for the image-processing lab. Students compare sequential and parallel Java implementations and evaluate how task partitioning and thread execution affect performance.

The lab materials include a student-facing lab handout and a code package. Students use these materials to implement and evaluate image-processing operations while connecting observed program behavior to PDC concepts such as data parallelism, speedup, synchronization, and load balancing.
