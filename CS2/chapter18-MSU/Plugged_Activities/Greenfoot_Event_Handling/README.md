## Implementation Notes

This activity uses Greenfoot to introduce event handling in an interactive Java environment. The event-handling slides take about 30 minutes and introduce the main concepts. The project introduction and sample project take about 20 additional minutes. Students design games that respond to mouse and keyboard input and use the Greenfoot framework to practice event-driven programming concepts.
