## PDC Activities

The first PDC component was implemented through **Parallel Image Processing**
in Module 3. This plugged activity used image processing as the context for
introducing data parallelism, multithreading, speedup, scalability,
synchronization, load balancing, and performance evaluation. The activity used
two 85-minute class meetings: one for lecture and sample-code demonstration,
and one for the image-processing lab. Materials are located in
[`Plugged_Activities/Image_Processing/`](Plugged_Activities/Image_Processing/).

The second plugged activity was implemented through **Greenfoot Event
Handling** in Module 9. This activity introduced event-driven programming,
asynchronous input, callbacks, interactive execution, and framework-controlled
program flow through a Greenfoot game-design project. Materials are located in
[`Plugged_Activities/Greenfoot_Event_Handling/`](Plugged_Activities/Greenfoot_Event_Handling/).
