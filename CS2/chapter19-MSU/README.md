# CSIT 112 – Fundamentals of Programming II

This repository contains course and instructional materials developed for
CSIT 112 at Montclair State University. The course package integrates parallel
and distributed computing (PDC) concepts into a CS2 course through two plugged
activities: **Parallel Image Processing** and **Greenfoot Event Handling**.

## PDC Integration

The first plugged activity, **Parallel Image Processing**, introduces PDC
concepts through sequential and multithreaded Java programs. Students compare
program behavior and performance while studying data parallelism, speedup,
scalability, synchronization, load balancing, and performance evaluation.

The second plugged activity, **Greenfoot Event Handling**, introduces
event-driven programming through an interactive game-design project. Students
develop Java games that respond to mouse and keyboard input and practice
asynchronous, framework-controlled program execution.

## Student Privacy and Data Sharing

No identifiable student data should be included in this public repository.
Evaluation materials are limited to anonymized or aggregate data and
public-shareable analysis outputs. When student-level data cannot be shared
because of participant-privacy or IRB restrictions, the repository provides
aggregate summaries or a note explaining the restriction.
