# CS1 C++ Course Materials for Parallel and Distributed Computing (PDC)

This repository contains instructional materials developed for integrating introductory Parallel and Distributed Computing (PDC) concepts into a C++-based CS1 course at Webster University. The materials accompany the corresponding chapter in the CDER CS1CS2 PDC E-book and include lecture materials, animations, unplugged activities, programming demonstrations, assignments, and supporting resources.
