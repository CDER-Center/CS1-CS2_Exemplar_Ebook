The Plugged-in Penny Activity builds on the unplugged Penny Activity by introducing students to the implementation of sequential and parallel sorting in Java. It helps students connect the parallel computing concepts explored during the hands-on activity with practical programming techniques used in modern software development.
Two Java programs support the activity. The first establishes a sequential baseline for comparison, while the second demonstrates multiple approaches to parallel programming using Java's built-in parallel libraries and the Fork/Join framework. By comparing the execution and performance of these programs, students gain an understanding of how modern programming languages and libraries support parallel execution.
Designed for introductory computer science students with little or no prior experience in parallel programming, the activity provides an accessible introduction to Java's parallel programming features. It reinforces the concepts introduced in the unplugged activity.
