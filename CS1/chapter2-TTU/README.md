# CSC 1300 Course Package - Tennessee Technological University

This repository contains materials for an introductory computer science course at Tennessee Technological University (TNTECH).

## Course Information

| Field | Details |
| --- | --- |
| **Institution** | Tennessee Technological University (TNTECH) |
| **Course** | CSC 1300: Introduction to Problem Solving and Computer Programming |
| **Course level** | CS1 |
| **Programming language** | C++ |
| **E-book chapter** | Chapter 3: CS1 Course Package - TNTECH |

## Activities

### Unplugged Activities

- Unplugged Penny Search Activity
- Unplugged Flag Maker Activity

### Plugged-In Activities

- Plugged-In Earthquake Tracker Assignment
